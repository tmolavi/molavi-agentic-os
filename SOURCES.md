# Sources & Technical Standards

This document catalogs the open specifications, architectural standards, and technical protocols upon which **TM AI Agent Toolkit** is built.

---

## 1. Open Standards & Protocols

| Standard / Specification | Governing Body | Applied Concept in TM Toolkit |
|---|---|---|
| **Agent Skills Specification** | Open Agent Community | Standardized `SKILL.md` format, trigger conditions, and schemas |
| **Model Context Protocol (MCP)** | Anthropic & Open Community | Structured tool execution and context schema standards |
| **JSON-LD & Schema.org** | W3C Semantic Web | Knowledge graph entity resolution for SEO & GEO auditors |
| **RFC 2104 (HMAC Authentication)** | IETF | Cryptographically signed Approval Tickets for human verification |
| **Core Web Vitals Metric Suite** | Chromium / Google | LCP, INP, and CLS diagnostic thresholds in SEO auditing skills |
| **PEP 557 (Data Classes)** | Python Software Foundation | Strict typed schema validation for canonical agents and workflows |
| **Clean Architecture & SOLID** | Robert C. Martin | Minimal diffs, decoupled engine abstractions, and zero-leak dependencies |
