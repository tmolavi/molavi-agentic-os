# Sources & Prior Art Attribution

This document catalogs the open-source projects, research specifications, and community repositories studied during the design of **Molavi Agentic OS**.

In accordance with our strict open-source licensing policy:
* No copyrighted code was copied without license compatibility.
* Unlicensed code was treated as reference-only and completely re-architected in a clean-room environment.
* Where code patterns were adapted from MIT or Apache-2.0 sources, full attribution is preserved below and in `THIRD_PARTY_NOTICES.md`.
