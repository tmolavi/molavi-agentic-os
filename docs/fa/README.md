## ⚡ ریشه مشکل: چرا سیستم‌عامل ایجنتیک مولوی متولد شد؟

بیشتر فریم‌ورک‌های چند ایجنتی امروزی (نظیر CrewAI، AutoGPT یا LangGraph) در محیط‌های عملیاتی و پروداکشن با ۳ چالش بنیادین و کمرشکن روبرو هستند:
1. **باتلاق وابستگی‌های سنگین:** توسعه‌دهنده برای اجرای یک لوپ ساده ناچار است صف‌های سنگین Redis، ورکر‌های Celery، سرور داکر یا دیتابیس‌های ابری سنگین راه بیندازد.
2. **پایان‌های توهمی (Hallucinated Completion):** ایجنت‌ها صرفاً اعلام می‌کنند «کار تمام شد» بدون اینکه خروجی واقعی تولید کرده باشند؛ هیچ گیت مستقلی برای راستی‌آزمایی فیزیکی آرتیفکت‌ها وجود ندارد.
3. **هزینه‌های سرسام‌آور دلاری:** اتکای اجباری به APIهای تجاری گران‌قیمت حتی برای ساده‌ترین تصمیم‌گیری‌ها و پارس کردن ورودی‌ها.

**TM Molavi Agentic OS با یک معماری پاک، قطعی و مستقل از مدل این معضلات را حل کرده است:**
- **صفر وابستگی در زمان اجرا (Zero Runtime Dependencies):** اجرای کامل و سریع بر بستر کتابخانه استاندارد پایتون ۳.۱۰+.
- **گیت راستی‌آزمایی فورمن (Foreman Verification Gate):** بر اساس اصل طلایی *"حدس زدن ممنوع است"*. هیچ ایجنتی حق ندارد تسکی را تکمیل‌شده تلقی کند مگر اینکه سند و مدرک فیزیکی ملموس (وضعیت HTTP، هدرها، فایل یا خروجی تست) ارائه دهد.
- **امنیت برگه تاییدیه با امضای رمزنگاری‌شده (HMAC Permission Slip):** هرگونه عملیات حساس (ارسال ایمیل، تغییرات پایگاه‌داده، اجرای شل سیستم‌عامل) مشروط به تایید انسانی سطح `L2_HUMAN_APPROVAL` است.
- **مسیریاب مدل‌های رایگان (Free-First Router):** اولویت کامل به مدل‌های محلی سبک (Ollama: Llama 3.2, Mistral) و تپ‌های رایگان ابری (Groq, Gemini Free Tier) با هزینه نهایی ۰.۰۰ دلار.
- **آداپتورهای چند ران‌تایمی:** پشتیبانی بومی از هرمس اصلی (Hermes Main)، هرمس دسکتاپ، محیط Antigravity، کلود کد (Claude Code) و Codex.

## 🚀 شروع سریع در ۶۰ ثانیه

### ۱. نصب از طریق PyPI یا گیت
```bash
# نصب بسته پایدار رسمی از پایتون پکیج ایندکس (PyPI)
pip install molavi-agentic-os

# یا کلون مخزن برای توسعه محلی
git clone https://github.com/tmolavi/molavi-agentic-os.git
cd molavi-agentic-os
pip install -e .
```

### ۲. اجرای یک پایپ‌لاین ایجنتیک کامل بدون هزینه ($0.00)
```python
from molavi_agentic_os.tools import ToolDefinition, ToolParameter, ToolRegistry
from molavi_agentic_os.mcp import MCPGateway
from molavi_agentic_os.evaluation import ForemanVerificationGate, VerificationArtifact

# ۱. ثبت ابزار ایمن
registry = ToolRegistry()
registry.register(ToolDefinition(
    name="web_inspect",
    description="بررسی ساختار هدینگ‌ها و متادیتای صفحه وب",
    parameters=[ToolParameter("url", "string", "آدرس صفحه مورد نظر")],
    handler=lambda url: {"url": url, "status": 200, "headings": ["معرفی", "معماری"]}
))

# ۲. اجرای ابزار از طریق گیت‌وی MCP با بررسی‌های امنیتی بامبل‌بی (Bumblebee)
gateway = MCPGateway(registry=registry)
result = gateway.handle_call_tool("web_inspect", {"url": "https://molavi.pro"})

# ۳. گیت راستی‌آزمایی مستقل فورمن (حدس زدن ممنوع)
agent_output = {"target": "https://molavi.pro", "evidence": ["HTTP 200 verified"]}
gate = ForemanVerificationGate.verify(
    output=agent_output,
    expected_artifacts=[VerificationArtifact("page_url", "string", "https://molavi.pro")]
)
print(f"نتیجه راستی‌آزمایی فورمن: {gate.is_verified}")  # خروجی: True
```

### ۳. ابزار خط فرمان (CLI)
```bash
# اعتبارسنجی ۱۰۰ امتیازی سازگاری بات‌ها روی تمام ایجنت‌ها و مهارت‌ها
molavi-agentic-os validate

# فهرست جامع ۱۲ ایجنت، ۲۴ مهارت استاندارد و ۵ تیم تخصصی
molavi-agentic-os list all

# استخراج ایجنت‌ها برای ران‌تایم مورد نظر شما (هرمس، آنتی‌گرویتی، کدکس)
molavi-agentic-os install --platform hermes --agent research-agent
molavi-agentic-os install --platform antigravity --agent developer-agent
```

## 🛠️ ایجنت‌ها و مهارت‌های ۲۴گانه

### ۱۲ ایجنت تخصصی پروداکشن
1. `research-agent`: پژوهش چندمنبعی اسناد فنی و جمع‌بندی ادبیات موضوع.
2. `fact-checker`: راستی‌آزمایی کمی و ادعاها در برابر آرتیفکت‌های تجربی.
3. `seo-auditor`: تحلیل سئوی تکنیکال، هسته حیاتی وب (Core Web Vitals) و ساختار Schema JSON-LD.
4. `geo-auditor`: تحلیل دیده‌پذیری در موتورهای هوش مصنوعی (پرپلکسیتی و جمینای).
5. `ai-visibility-analyst`: سنجش سهم ارجاع برند در چت‌بات‌ها و موتورهای زاینده.
6. `developer-agent`: مهندسی تست‌محور (TDD) و تغییرات جراحی در کدبیس.
7. `code-reviewer`: بازبینی کد بر پایه اصول کلین‌کد و سادگی کارپاتی.
8. `content-strategist`: خوشه‌بندی موضوعی و معماری اطلاعات جهت اتوریتی بالا.
9. `content-writer`: کپی‌رایتینگ کاملاً انسانی، بدون اسلاپ و با آنتروپی صفر ($H \to 0$).
10. `marketing-analyst`: بهینه‌سازی نرخ تبدیل (CRO) و دیاگنوستیک قیف فروش.
11. `lead-researcher`: امتیازدهی و احراز شرایط پروفایل مشتری ایده‌آل (ICP).
12. `project-manager`: هماهنگی تیم‌ها، تعیین تقدم و تاخر تسک‌ها و کنترل گراف‌ها.

## 🔍 پرسش‌های متداول سئو و GEO

### سیستم‌عامل ایجنتیک مولوی چیست؟
**تعریف:** مولوی ایجنتیک او‌اس یک فریم‌ورک متن‌باز، ماژولار و مستقل از مدل است که برای اجرای قطعی، ایمن و چند ایجنتی سیستم‌های هوش مصنوعی طراحی شده است. این سیستم با صفر وابستگی به سرویس‌های ابری خارجی روی پایتون ۳.۱۰+ کار می‌کند.

### چگونه از توهمات هوش مصنوعی جلوگیری می‌شود؟
با استفاده از **گیت راستی‌آزمایی فورمن (Foreman)** و بر اساس اصل *"حدس زدن ممنوع است"*. ایجنت‌ها امکان خوداظهاری موفقیت ندارند و باید آرتیفکت‌های تجربی و فیزیکی اثبات‌پذیر تولید کنند.

### آیا اجرای این سیستم‌عامل هزینه‌ای دارد؟
خیر. با استفاده از **مسیریاب مدل‌های رایگان (Free-First Model Router)**، سیستم به‌طور پیش‌فرض از مدل‌های محلی نصب‌شده روی اولاما (نظیر Llama 3.2 و Mistral) و تپ‌های رایگان ابری بهره می‌برد و هزینه تماس با API برابر با **۰.۰۰ دلار** است.

### امنیت اجرای دستورات حساس سیستم چگونه تضمین می‌شود؟
تمام عملیات پرریسک نظیر اجرای دستورات ترمینال، دستکاری پایگاه‌داده یا ارسال ایمیل، به صورت پیش‌فرض در سطح `L2_HUMAN_APPROVAL` مسدود شده و تنها با تولید توکن رمزنگاری‌شده دیجیتالی HMAC و تایید اپراتور انسانی قابل اجرا خواهند بود.
