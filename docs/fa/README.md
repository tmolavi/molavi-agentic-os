## ۱. معرفی و فلسفه پروژه

**TM AI Agent Toolkit** (شناخته‌شده با نام مولوی ایجنتیک او‌اس) یک فریم‌ورک متن‌باز، ماژولار و مستقل از مدل است که تحت اکوسیستم متن‌باز **TM (تقی مولوی - Taqi Molavi)** برای سیستم‌های ایجنتیک پیشرفته توسعه یافته است.

بر خلاف لیست‌های تبلیغاتی یا پرامپت‌های خام شبکه‌های اجتماعی، این پروژه حاصل **آدیت فنی عمیق ۲۰ ریپوزیتوری پیشرو** در اکوسیستم هوش مصنوعی است و بر سه ستون اصلی استوار است:

۱. **استراتژی اولویت مدل‌های رایگان (Free-First):** اجرای کامل و بدون هزینه روی مدل‌های محلی سبک (Ollama / Llama 3) و تپ‌های رایگان ابری (Groq, Gemini Free Tier) پیش از هرگونه رجوع به مدل‌های پولی.
۲. **امنیت تضمین‌شده با تایید انسانی (Permission-Slip):** هرگونه عملیات حساس (ارسال ایمیل، انتشار پست، تغییرات سرور، تراکنش مالی) طبق سطح `L2_HUMAN_APPROVAL` متوقف شده و تیکت امضاشده دیجیتالی با تایید اپراتور صادر می‌کند.
۳. **گیت راستی‌آزمایی فورمن (Foreman - قانون طلایی: حدس زدن ممنوع):** هیچ ایجنتی حق ندارد تسک را «انجام شد» علامت بزند مگر اینکه آرتیفکت و شواهد تجربی و واقعی (لینک، داکیومنت، خروجی تست) ارائه دهد.

## ۲. مشخصات و تحویل‌های نسخه اولیه (MVP v0.1.0)

* **۱۲ ایجنت تخصصی با امتیاز ۱۰۰/۱۰۰ در اعتبارسنجی Bot-Ready:**
  - `research-agent`: تحلیل‌گر ارشد پژوهش و گردآوری داده با استناد به منابع اولیه
  - `seo-auditor`: آدیتور تکنیکال سئو، ساختار اسکیما و Core Web Vitals
  - `geo-auditor`: متخصص سئوی هوش مصنوعی (GEO) و دیده‌شدن در چت‌بات‌ها (Perplexity, ChatGPT, Gemini)
  - `ai-visibility-analyst`: تحلیل سهم صدای برند (Share of Voice) در پاسخ‌های هوش مصنوعی
  - `content-strategist`: استراتژیست کلاستر محتوایی و خوشه‌های اعتبار موضوعی
  - `content-writer`: نویسنده تکنیکال و مقالات عمقی بدون پرتی‌های کلامی هوش مصنوعی (Unslop)
  - `fact-checker`: فکت‌چکر مستقل و سنجش اعتبار گزاره‌ها با شواهد
  - `code-reviewer`: بازبین ارشد کد، امنیت و استانداردهای Clean Code
  - `developer-agent`: توسعه‌دهنده سیستم‌های ماژولار با تست‌های یونیت پایدار
  - `marketing-analyst`: تحلیل‌گر فانل، شاخص‌های تبدیل و هوش بازاریابی
  - `lead-researcher`: پژوهشگر اکانت‌های کلیدی B2B و احراز صلاحیت ICP
  - `project-manager`: مدیر عملیات، شکستن پروژه‌ها و مدیریت صف تسک‌ها

* **۱۵ مهارت استاندارد Agent Skills (`SKILL.md`):**
  - از مهارت‌های وب، سئو، GEO، فکت‌چکینگ و پاکسازی Slop تا صف‌های پردازش موازی و حافظه محلی SQLite.

* **۵ تیم چند ایجنتی و ۵ پایپ‌لاین کاری:**
  - تیم تحقیق سئو و GEO، تیم مانیتورینگ دیده‌شدن در هوش مصنوعی، تیم تولید محتوای معتبر، تیم توسعه نرم‌افزار، و تیم جذب سرنخ B2B با تایید انسانی.

## ۳. نحوه راه‌اندازی و استفاده سریع

```bash
# کلون و نصب پکیج
git clone https://github.com/tmolavi/molavi-agentic-os.git
cd molavi-agentic-os
pip install -e .

# اعتبارسنجی Bot-Ready تمام ایجنت‌ها
molavi-agentic-os validate

# لیست تمام ایجنت‌ها، مهارت‌ها و تیم‌ها
molavi-agentic-os list all

# خروجی گرفتن برای ابزارهای مختلف (Codex, Hermes, Claude Code, Antigravity)
molavi-agentic-os install --platform codex --agent seo-auditor
molavi-agentic-os install --platform hermes --agent research-agent
```
