## 1. Layihə Haqqında

### Əsas Üstünlüklər:
* **Ödənişsiz Modellərə Üstünlük:** Ollama vasitəsilə lokal modellərdən və pulsuz bulud sistemlərindən (Groq, Gemini) istifadə edir.
* **Təhlükəsizlik və İnsan Təsdiqi (Permission-Slip):** Həssas əməliyyatlar (e-poçt göndərilməsi, server dəyişiklikləri) insan tərəfindən rəqəmsal imzalı təsdiq tələb edir.
* **Foreman Dəqiqlik Qaydası:** Sübut və real artefaktlar olmadan heç bir tapşırıq tamamlanmış sayılmır.
